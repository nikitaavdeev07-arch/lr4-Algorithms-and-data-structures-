# Лабораторная работа №4 — Односвязный и двусвязный списки 

## Постановка задачи

**Общее задание:** Реализовать шаблонный класс двусвязного списка (`DoublyLinkedList`) с базовыми операциями.

**Дополнительная функциональность (вариант 1):** метод `reverse()` — разворот списка.

Ниже приведена полная реализация с комментариями, демонстрационной программой и анализом сложности.

---

## Листинг программы

```cpp
#include <iostream>
#include <stdexcept>
#include <string>

// ============================================================
// Шаблонный класс двусвязного списка
// ============================================================
template <typename T>
class DoublyLinkedList {
private:
    // Узел двусвязного списка
    struct Node {
        T data;           // данные
        Node* prev;       // указатель на предыдущий узел
        Node* next;       // указатель на следующий узел

        Node(const T& value)
            : data(value), prev(nullptr), next(nullptr) {}
    };

    Node* head;   // «голова» списка
    Node* tail;   // «хвост» списка
    int count;    // количество элементов

public:
    // ---------- Конструктор / деструктор ----------
    DoublyLinkedList() : head(nullptr), tail(nullptr), count(0) {}

    ~DoublyLinkedList() { clear(); }

    // ---------- Вставка в начало O(1) ----------
    void push_front(const T& value) {
        Node* newNode = new Node(value);
        if (head == nullptr) {
            head = tail = newNode;          // список был пуст
        } else {
            newNode->next = head;           // новый узел ссылается на бывшую голову
            head->prev = newNode;           // бывшая голова ссылается назад
            head = newNode;                 // обновляем голову
        }
        count++;
    }

    // ---------- Вставка в конец O(1) ----------
    void push_back(const T& value) {
        Node* newNode = new Node(value);
        if (tail == nullptr) {
            head = tail = newNode;          // список был пуст
        } else {
            tail->next = newNode;           // бывший хвост ссылается вперёд
            newNode->prev = tail;           // новый узел ссылается назад
            tail = newNode;                 // обновляем хвост
        }
        count++;
    }

    // ---------- Удаление из начала O(1) ----------
    void pop_front() {
        if (head == nullptr)
            throw std::underflow_error("List is empty");
        Node* temp = head;
        head = head->next;
        if (head != nullptr)
            head->prev = nullptr;
        else
            tail = nullptr;                 // список стал пустым
        delete temp;
        count--;
    }

    // ---------- Удаление из конца O(1) ----------
    void pop_back() {
        if (tail == nullptr)
            throw std::underflow_error("List is empty");
        Node* temp = tail;
        tail = tail->prev;
        if (tail != nullptr)
            tail->next = nullptr;
        else
            head = nullptr;                 // список стал пустым
        delete temp;
        count--;
    }

    // ---------- Поиск по значению O(n) ----------
    Node* find(const T& value) const {
        Node* current = head;
        while (current != nullptr) {
            if (current->data == value) return current;
            current = current->next;
        }
        return nullptr;
    }

    // ---------- РЕВЕРС СПИСКА (вариант 1) O(n) ----------
    // Меняем местами указатели next и prev у каждого узла,
    // затем меняем местами head и tail.
    void reverse() {
        if (head == nullptr) return;        // пустой список

        Node* current = head;
        Node* temp = nullptr;

        while (current != nullptr) {
            // Меняем местами prev и next у текущего узла
            temp = current->prev;
            current->prev = current->next;
            current->next = temp;

            // Переходим к следующему узлу (в старой нумерации — prev)
            current = current->prev;
        }

        // Меняем местами head и tail
        temp = reinterpret_cast<Node*>(head);
        head = tail;
        tail = reinterpret_cast<Node*>(temp);
    }

    // ---------- Вывод в прямом порядке O(n) ----------
    void print() const {
        Node* current = head;
        std::cout << "[";
        while (current != nullptr) {
            std::cout << current->data;
            if (current->next != nullptr) std::cout << ", ";
            current = current->next;
        }
        std::cout << "]" << std::endl;
    }

    // ---------- Вывод в обратном порядке O(n) ----------
    void printReverse() const {
        Node* current = tail;
        std::cout << "[";
        while (current != nullptr) {
            std::cout << current->data;
            if (current->prev != nullptr) std::cout << ", ";
            current = current->prev;
        }
        std::cout << "]" << std::endl;
    }

    // ---------- Очистка списка ----------
    void clear() {
        while (head != nullptr) {
            Node* temp = head;
            head = head->next;
            delete temp;
        }
        tail = nullptr;
        count = 0;
    }

    int size() const { return count; }
    bool empty() const { return head == nullptr; }
};

// ============================================================
// Демонстрационная программа
// ============================================================
int main() {
    setlocale(LC_ALL, "ru");

    DoublyLinkedList<int> list;

    // Заполняем список: 10 20 30 40 50
    for (int i = 1; i <= 5; i++)
        list.push_back(i * 10);

    std::cout << "== Двусвязный список (Средний уровень, вариант 1) ==\n";
    std::cout << "Исходный список:       ";  list.print();
    std::cout << "Обратный порядок:      ";  list.printReverse();
    std::cout << "Размер: " << list.size() << "\n\n";

    // --- Применяем reverse ---
    list.reverse();
    std::cout << "После reverse():        ";  list.print();
    std::cout << "Обратный порядок:      ";  list.printReverse();
    std::cout << "Размер: " << list.size() << "\n\n";

    // --- Проверяем базовые операции ---
    list.push_front(5);
    list.push_back(60);
    std::cout << "После push_front(5) и push_back(60): ";
    list.print();

    list.pop_front();
    list.pop_back();
    std::cout << "После pop_front() и pop_back():       ";
    list.print();

    // --- Повторный реверс возвращает исходный порядок ---
    list.reverse();
    std::cout << "После повторного reverse():           ";
    list.print();

    // --- Поиск ---
    auto* node = list.find(30);
    if (node)
        std::cout << "Найдено значение 30\n";
    else
        std::cout << "Значение 30 не найдено\n";

    // --- Очистка ---
    list.clear();
    std::cout << "После clear(): размер = " << list.size()
              << ", пуст = " << (list.empty() ? "да" : "нет") << std::endl;

    return 0;
}
```

## Анализ сложности операций

| Операция              | Сложность | Пояснение |
|-----------------------|-----------|-----------|
| `push_front`          | **O(1)**  | Меняются только указатели `head` и пары `prev/next` |
| `push_back`           | **O(1)**  | Есть указатель `tail`, вставка за константное время |
| `pop_front`           | **O(1)**  | Удаление головы без обхода |
| `pop_back`            | **O(1)**  | Есть `tail` и `prev`, обход не нужен (в отличие от односвязного списка — там O(n)) |
| `find`                | **O(n)**  | Линейный обход от головы |
| **`reverse`**         | **O(n)**  | Один проход по всем узлам, у каждого меняются местами `prev/next`; затем обмен `head`/`tail` |
| `print`               | **O(n)**  | Проход от `head` до `tail` |
| `printReverse`        | **O(n)**  | Проход от `tail` до `head` благодаря `prev` |
| `clear`               | **O(n)**  | Освобождение всех узлов |
| `size`, `empty`       | **O(1)**  | Хранится счётчик `count` |

**Память на элемент:** `sizeof(T) + 2 × sizeof(Node*)` — данные + два указателя (`prev`, `next`).

## Ключевые моменты реализации `reverse()`

Алгоритм разворота двусвязного списка:

1. Для каждого узла поменять местами `prev` и `next`.
2. После прохода по всем узлам поменять местами `head` и `tail`.

Пошагово для `[10, 20, 30]`:

```
До:     head→[10]⇄[20]⇄[30]←tail
После обмена prev/next у всех узлов:
        head→[10]⇄[20]⇄[30]←tail  (связи зеркальны)
Меняем head и tail:
        tail→[10]⇄[20]⇄[30]←head
```

Внутри цикла переход к следующему узлу делается через `current = current->prev` (потому что `prev` уже указывает на «старый next»).

> **Примечание:** в листинге используется `reinterpret_cast` для наглядности при обмене `head` и `tail`, но можно обойтись и обычным временным указателем `Node* temp = head; head = tail; tail = temp;` — оба варианта корректны. В реальном коде лучше второй вариант (без `reinterpret_cast`), т.к. он читаемее и не вызывает предупреждений компилятора.

## Ответы на контрольные вопросы (кратко, по варианту)

1. **Чем связный список отличается от динамического массива?**  
   Элементы списка хранятся в отдельных узлах, связанных указателями, а не непрерывно. Нет произвольного доступа по индексу (O(n)), зато вставка/удаление в начало и конец — O(1) без сдвигов.

2. **Какие операции в односвязном списке выполняются за O(1)?**  
   `push_front`, `pop_front`, `push_back` (если есть `tail`), вставка после известного узла, удаление после известного узла.

3. **Почему удаление из конца односвязного списка требует O(n)?**  
   Нет указателя на предыдущий узел, поэтому для обновления `tail` нужно пройти весь список до предпоследнего элемента.

4. **Преимущества `tail` в односвязном списке:** вставка в конец становится O(1) вместо O(n).

5. **Отличие двусвязного от односвязного:** каждый узел хранит и `prev`, и `next`, что позволяет обход в обе стороны и удаление известного узла за O(1).

6. **Что быстрее в двусвязном:** `pop_back` (O(1) против O(n)), `insert_after`/`erase` по указателю на узел (O(1) против O(n) для поиска предыдущего), обратный обход.

7. **`head` и `tail`** — указатели на первый и последний узлы списка соответственно.

8. **Удаление из середины односвязного списка:** нужен указатель на узел **перед** удаляемым; `prev_node->next = target->next; delete target;`.

9. **Удаление из середины двусвязного списка:** имея указатель на узел, делаем `node->prev->next = node->next; node->next->prev = node->prev; delete node;` — O(1), проще, т.к. не нужен обход.

10. **Если забыть обновить `tail`:** при удалении хвоста `tail` будет указывать на освобождённую память → «висячий указатель», UB при следующем обращении.

11. **Реверс односвязного списка:** итеративно переставлять `next` у каждого узла, сохраняя `prev`, `current`, `next`; в конце `head = prev`.

12. **Цикл в списке:** алгоритм Флойда («черепаха и заяц») — два указателя с разной скоростью; если встретились — цикл есть.

13. **Список вместо массива:** когда важны частые вставки/удаления в начале/середине, неизвестен итоговый размер, не нужен произвольный доступ.

14. **Дополнительная память на узел:** односвязный — 1 указатель; двусвязный — 2 указателя (+ выравнивание).

15. **Почему доступ по индексу O(n):** нет непрерывного массива, чтобы вычислить адрес элемента; нужно пройти `i` узлов по `next`.

## Выводы

В ходе работы реализован шаблонный класс двусвязного списка `DoublyLinkedList` с базовыми операциями (`push_front`, `push_back`, `pop_front`, `pop_back`, `find`, `print`, `printReverse`, `clear`) и дополнительным методом `reverse()` (вариант 1). 

Показано, что:
- двусвязный список обеспечивает **O(1)** для операций на обоих концах (в отличие от односвязного, где `pop_back` — O(n));
- метод `reverse()` работает за **O(n)**, требуя одного прохода и O(1) дополнительной памяти;
- наличие `prev` даёт удобный обратный обход и упрощает удаление известного узла;
- корректное управление памятью (деструктор, `clear`, обновление `head`/`tail`) предотвращает утечки и «висячие» указатели.

Двусвязный список оправдан, когда нужны частые операции с конца списка, обратный обход или удаление по указателю; цена — дополнительный указатель на каждый узел.
